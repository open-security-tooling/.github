# Open Security Tooling

Open-source security tools that are **secure by design** and **easy for developers to adopt**.

- **Security-first.** The tools we ship hold themselves to the standard they enforce: signed commits, pinned dependencies, least-privilege CI, and safe defaults.
- **Dev-friendly.** Security that gets in the way gets turned off. We aim for clear output, low-friction setup, and sensible defaults.

### Found a vulnerability?

Please **don't open a public issue**. Report it privately through the affected repository's **Security → Report a vulnerability** tab. See our [security policy](https://github.com/open-security-tooling/.github/blob/main/SECURITY.md).
